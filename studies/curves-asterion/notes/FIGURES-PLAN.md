# Figures plan (names are fixed; the report writer places `@@FIG:name@@` where noted)

Generated by `build.py` from the report (no work needed): `twins` (§5), `timeline` (§6), `score` (§8), `stack` (§11),
`backlog` (§14). The hero figure (`hero`) is registered as a demo in `hero.html`.

Hand-made figures. Each is a `<!--FIG name-->…<!--/FIG-->` block in a `figsN.html` plus `reg('name', root => …)`
in a `demosN.js`. Every number comes from `notes/01-current-build.md` (constants with file:line), from
`atlas/data.json` and `atlas/data.summary.json` (creatures, items, spells), or from the twin notes; label
illustrative numbers "Illustrative". No screenshots or copyrighted art. Animations use `tick(dt)` and pause
offscreen (core.js does this). A figure that waits for a click auto-plays after ~2 s idle.
